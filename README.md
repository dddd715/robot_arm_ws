# 基于视觉的物料分拣机器人设计

本项目用于毕业设计，目标是识别物料颜色，并控制机械臂将物料抓取至指定区域。

## 当前内容

- `src/robot_arm_description/`：ROS 2 机械臂描述包，包含 URDF、RViz 启动文件和控制器配置。
- `docx/`：任务书、初步构思、物料参考图及机械臂与夹爪选型方案。

项目目前处于结构设计和仿真准备阶段，视觉分拣完整流程及实物性能尚待验证。

## 初步方案

- 上位机：个人电脑，使用 Python 和 OpenCV 进行颜色识别与坐标转换。
- 下位机：计划采用 STM32 执行运动控制。
- 机械结构：参考开源结构开展自主适配设计，实物优先使用匹配的套件或半成品。
- 物料：彩色几何积木，商家反馈单件约 85 g，尺寸及质量待实测。
- 首版实验：固定台面、物料分散摆放，优先验证正方体颜色分拣。

## 工作空间构建与显示

在已安装所需 ROS 2 环境及依赖的终端中，从工作空间根目录执行：

```bash
source /opt/ros/<你的ROS2发行版>/setup.bash
colcon build --symlink-install
source install/setup.bash
ros2 launch robot_arm_description display.launch.py
```

上述命令为工作空间的使用入口；具体 ROS 2 发行版和运行依赖以本机环境为准。构建与运行结果需在目标环境验证。

`build/`、`install/` 和 `log/` 为本地生成目录，已通过 `.gitignore` 排除。
